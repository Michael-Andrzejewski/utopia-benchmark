# 3. Perspectives

What this file holds:

Life on the ground, from inside the utopia. Enough different places, lives, and kinds of being that a reader finishes with a mental map of the whole. Vary region, age, role, and situation. Include ordinary time (an hour, a day, a week), not only notable moments. Each perspective should show something about the structure in part 2 that a reader could not have guessed from part 2 alone.

Delete these instructions when you write the entry.
